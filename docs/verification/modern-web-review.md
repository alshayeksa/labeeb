# مراجعة واجهة لبيب — Modern Web Guidance

النسخة: 0.1.15. التاريخ: 2026-11-13. البيئة: Windows x64.

## المشكلات قبل التنفيذ

1. تحديث حقل العنوان يعيد تصيير شريط التبويبات بأكمله. في خط الأساس: 1920 استدعاء لتصيير أيقونات 80 تبويبًا خلال 24 تغييرًا للحقل.
2. اقتراحات العنوان تعيد تحليل عناوين المكتبة وفرز المطابقات مع كل استعلام.
3. تحديث لقطة الحالة يستبدل مراجع الفروع التي لم تتغير، ويقارن اللقطة كاملة بتسلسل JSON.
4. إغلاق المساعد يزيل المكوّن ويفقد المسودة والمحادثة؛ لا توجد استعادة مناسبة للتركيز أو اختصار إرسال.
5. التبويبات تفتقر إلى تنقل الأسهم وHome/End/Delete. توجد مسافات حروف غير مناسبة للعربية وأنماط قوائم محذوفة.
6. تأكيد الحذف يعتمد على نافذة مخصصة مع إدارة تركيز يدوية حتى عند توفر dialog الأصلي.

## التحسينات المنفذة

- استخراج TabStrip وTabItem مع React.memo ومعالجات مستقرة؛ مشاركة مراجع فروع الحالة والصفوف غير المتغيرة بدل إعادة إنشائها. تحديثات الصفحة والعنوان والتحميل والتنزيلات ما زالت تمر عند تغير بياناتها.
- فهرس اقتراحات محلي مخزن بمفاتيح WeakMap، يعاد إنشاؤه عند تغيير السجل أو المفضلة. الحفاظ على ترتيب الأولويات، حد ست نتائج، إزالة التكرار ورفض الروابط غير الآمنة. لا إرسال لنص الكتابة لأي خدمة.
- إبقاء حالة المساعد في الذاكرة عند الإغلاق مع إزالة عناصره تمامًا من التخطيط؛ استعادة التركيز إلى زر المساعد، حفظ الردود التي تصل وهو مغلق، واستعادة السؤال عند فشل الطلب. Ctrl/Command+Enter للإرسال مع مراعاة IME وبديل requestSubmit. سجل حي للرسائل وتمرير يتوقف عندما يقرأ المستخدم رسائل أقدم.
- أسهم التبويبات تراعي RTL؛ Home/End وDelete متاحة، والتنشيط يبقى بالنقر أو Enter/Space. عنوان الوثيقة يطابق القسم الحالي.
- تأكيد الحذف يستخدم dialog.showModal عند توفره، دون مصيدة تركيز مخصصة في هذا المسار؛ يحتفظ ببديل Escape/Tab للإصدارات الأقدم. عناوين ARIA فريدة واستعادة التركيز للعنصر الذي فتح النافذة.
- خصائص اتجاه منطقية، إزالة تباعد حروف العناوين العربية، حد 24 بكسل لزر إغلاق التبويب، وإظهار تركيزه. تحميل مسبق لوزن Tajawal العربي 400 فقط مع إبقاء الأوزان الأخرى كما هي.
- scrollbar-gutter وfield-sizing داخل @supports؛ تبقى الأبعاد والتمرير الحاليان عند عدم الدعم. لا استخدام content-visibility على شريط التبويبات.
- إزالة CSS غير المستخدم لـ language-toggle وrail-more وdiagnostics-path/diagnostics-events، بعد البحث في المصدر. لا حذف لأي مكتبة: lucide-react مستخدمة في مصنع SVG، وبقية الاعتمادات المباشرة لها وظائف قائمة.

لم تتغير React أو Tauri أو معمارية التصفح أو محركات عرض الصفحات أو ألوان وتصميم لبيب الأساسي. لم يعدّل هذا العمل كود Obscura؛ كانت إزالته ضمن أعمال سابقة موجودة في مساحة العمل قبل هذه المراجعة. لم تُعكس تغييرات المستخدم السابقة.

## القياس قبل وبعد

السيناريو نفسه: 80 تبويبًا، 5000 سجل، 24 تغييرًا لحقل العنوان؛ 7 دفعات بحث بعد الإحماء و5 جولات واجهة بعد جولة إحماء. جهاز Intel Core Ultra 7 258V، Node 22.23.2، Vitest/jsdom، بناء React التطويري، وIPC وهمي.

| المقياس | قبل | بعد |
|---|---:|---:|
| وسيط زمن دفعة البحث المحلية | 47.1761 ms | 6.3410 ms |
| وسيط الزمن الكلي لتغييرات الحقل | 341.9628 ms | 106.8447 ms |
| وسيط مجموع actualDuration لتصييرات React الملتزمة | 288.6892 ms | 78.6727 ms |
| استدعاءات تصيير أيقونات التبويبات لكل جولة | 1920 | 0 |
| حزمة JavaScript غير مضغوطة | 367554 بايت | 371428 بايت |

النسب المحلية تقريبًا: البحث أقل 86.6%، وزمن React أقل 72.7%. هذه ليست نسب تسريع عامة للمتصفح. جولات زمن الحقل قبل: 209–824 ms؛ بعد: 75–192 ms، ما يدل على ضجيج ملحوظ في القياس. البحث يقيس الاستخدام الدافئ للفهرس؛ لا يقيس كلفة بناء الفهرس لأول مرة. لا يُستنتج منه تحسن INP أو زمن بدء التطبيق أو الذاكرة أو الرسم أو تحميل المواقع.

النتائج الخام وبصمات المصدر وأحجام الحزمة: [قبل](modern-web-before.json)، [بعد](modern-web-after.json).

إعادة قياس النسخة الحالية في PowerShell:

```powershell
$env:LABEEB_PERF_OUT='docs/verification/modern-web-repeat.json'
npx.cmd vitest run scripts/ui-performance.test.tsx --maxWorkers=1
```

الاختبار مشروط بمتغير البيئة فلا يضيف قياسًا زمنيًا هشًا إلى اختبارات الوظائف. ملف before محفوظ من المصدر السابق للتعديلات؛ تشغيل الأمر الآن يقيس المصدر الحالي فقط.

## التحقق وحدوده

- npm.cmd run check: نجح 70 اختبارًا؛ اختبار الأداء مستثنى افتراضيًا وشُغّل منفصلًا بنجاح.
- بناء Tauri/Rust للإصدار Windows x64: نجح.
- npm.cmd run build: نجح TypeScript وبناء الإنتاج. أعاد Vite كتابة رابط تحميل الخط إلى أصل محلي ذي بصمة؛ لا اعتماد على شبكة خارجية للخط.
- اختبارات جديدة للحالة والاقتراحات، تنقل التبويبات في الاتجاهين، مسودة المساعد والرد أثناء الإغلاق وفشل الطلب وIME، ومساري dialog الأصلي والبديل واستعادة التركيز.
- الاختبارات السابقة تشمل العنوان والاختصارات والشريط الجانبي والسمة والتنزيلات وViora والوسائط، ونجحت. لا تعني هذه النتيجة ضمان عدم وجود أي تراجع غير مغطى.
- لم يُجر اختبار رسم تفاعلي داخل WebView2 أو WKWebView لهذه الدفعة. مسار dialog الأصلي اختُبر بمحاكاة API؛ يلزم تحقق فعلي على macOS وWindows للتركيز والقارئ الصوتي وأبعاد العرض الأصلي. لم يقس هذا العمل أداء Rust أو IPC أو محرك التصفح.
- حزمة JavaScript زادت بنحو 3.9 KB غير مضغوطة بسبب السلوكيات الجديدة، رغم انخفاض كلفة التحديث المقاسة.

## Modern Web Guidance

استُخدم CLI الخاص بالمشروع للبحث ثم قراءة الأدلة performance وaccessibility وhtml، مع مراجعة توافق WebKit. لم تُضف أداة الإرشادات إلى اعتماديات التطبيق.

- طبقت performance: “DO preload critical fonts” بتحميل وزن الخط الأساسي فقط، وتجنبت العمل المتكرر في مسار الإدخال.
- طبقت accessibility: “Use the native `<dialog>` element” في تأكيد الحذف مع بديل توافق.
- طبقت html: “DO maintain focus” عند إغلاق نافذة التأكيد أو عمود المساعد.
