# Windows 0.1.50

Store packaging of the download diagnostic build after the user reported two
successful video downloads on the affected computer. Remove the raw downloader
stderr and exit status from the user-facing error message; retain bounded error
capture, preservation of errors over trailing warnings, and the two-second
stderr drain after process exit. Downloader arguments and pinned tools are
unchanged. The original failure's root cause remains unconfirmed.

Version: application 0.1.50, Microsoft Store package 0.1.50.0.
This release is prepared for manual Partner Center upload; it is not published.
The diagnostic build's user test is not a test of the final MSIX installation.
