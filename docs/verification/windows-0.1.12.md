# Labeeb 0.1.12 — downloaded media library

Downloads now leads with a responsive media grid: local preview image, title, size/date, play using the system's associated media player, and open containing folder. Search filters by title. Manual URL entry is a collapsed optional section; running/failed jobs retain their controls below the library. Existing inline video buttons remain unchanged.

Completed YouTube and direct media downloads register a local JSON index. Opening Downloads also discovers completed media in the default Labeeb download folder from older versions. Records for custom destinations persist across restart. Deleted/missing files are omitted from the displayed library; arbitrary paths cannot be supplied to play/thumbnail commands (only a known library ID).

Thumbnails are generated from the saved local file with the existing hash-verified FFmpeg, one at a time, on demand as cards approach the viewport. Each subprocess has a ten-second timeout, local-only protocol whitelist, one decoder thread, hidden window and kill-on-drop. JPEG files are cached by file identity, size and modification time. No thumbnail tool download occurs and the browser's normal snapshots do not carry images.

Validation: frontend typecheck and 52 tests passed. Final Rust release suite: 25 passed, 3 optional integrations ignored. The local FFmpeg integration was explicitly run separately and passed: real JPEG generation and reuse of the same cache file. Persistence, missing-file handling, and refusal of unknown media IDs passed. Native 0.1.12 launched successfully. Its accessibility tree showed all three pre-existing media cards with titles, sizes, play and folder controls. The native library created three cached JPEGs (13,085 / 19,852 / 13,085 bytes), persisted all three records, and left no FFmpeg process running. Active user navigation overlapped screenshot capture, so no further input or OS-player launch was attempted. Release NSIS build succeeded (31.23 MiB). Playback uses the OS media association; this is not an embedded player. Older downloads in custom folders that were never indexed cannot be automatically discovered. No delete action is introduced.
