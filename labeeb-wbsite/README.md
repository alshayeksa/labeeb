# موقع لبيب

موقع تسويقي ثابت بالعربية والإنجليزية، جاهز لـ Cloudflare Pages. المسار المعتمد هو `labeeb-wbsite` لأنه يحتوي الصور الأصلية، بما فيها `28-video-downlaod.png`.

## الرفع المباشر

1. افتح Cloudflare ثم Workers & Pages وأنشئ مشروع Pages باستخدام Direct Upload.
2. ارفع `labeeb-cloudflare.zip` أو مجلد `dist` كاملًا.
3. تأكد أن `index.html` في جذر الملفات المرفوعة، وليس داخل مجلد إضافي.

العربية هي الصفحة الرئيسية، والإنجليزية في `/en/`. لا يحتاج الموقع إلى خادم تطبيقات أو قاعدة بيانات أو مفاتيح أو متغيرات بيئة. لم يُنشر الموقع تلقائيًا.

مرجع الرفع: https://developers.cloudflare.com/pages/get-started/direct-upload/

## التعديل وإعادة البناء

عدّل النصوص في `build.mjs` والتصميم في `style.css` والسلوك في `app.js`، ثم نفّذ:

```powershell
node build.mjs
```

المخرجات في `dist`. لا ترفع ملفات المصدر أو مجلد `qa` بدلًا منها. أعد إنشاء ملف ZIP بعد أي تعديل:

```powershell
Compress-Archive -Path .\dist\* -DestinationPath .\labeeb-cloudflare.zip -Force
```

للربط بمستودع Git: اجعل دليل المشروع `labeeb-wbsite`، وأمر البناء `node build.mjs`، ودليل النشر `dist`.

للمعاينة المحلية:

```powershell
python -m http.server 1439 --bind 127.0.0.1 --directory dist
```

ثم افتح `http://127.0.0.1:1439/`. يمكن أيضًا فتح `dist/index.html` مباشرةً لمراجعة الصفحة العربية.

## الصور والأداء

- صورة «عن لبيب» هي أول لقطة للمنتج وتعرض المطور والدولة.
- الصور الأصلية في `images` محفوظة دون تغيير. النسخ المضغوطة بصيغة WebP في `assets`.
- `prepare-assets.py` أداة اختيارية لإعادة توليد الصور من المشروع الأصلي، وتحتاج Python وPillow.
- الخطوط محلية، ولا توجد أدوات تحليل أو تعقب أو مكتبات JavaScript خارجية.
- يمكن تكبير الصور، وتبديل صور ميزة التحميل باستخدام الفأرة أو لوحة المفاتيح.
- `qa` يحتوي صور المعاينة ونتائج اختبار اللغتين بأربعة عروض للشاشة. `verify.mjs` يستخدم Playwright الموجود في بيئة المشروع الأصلية؛ ليس مطلوبًا للبناء أو النشر.

## دقة المحتوى

المزايا راجعت مصدرها في AboutFeatures.tsx وAboutPanel.tsx وSettingsPanel.tsx وVideoDownloads.tsx. لم تُضف أرقام سرعة أو مقارنة استهلاك ذاكرة غير مقاسة، أو فريق عمل غير مذكور في المصدر. تعرض الصفحة المطور شايع الشايع.

WebView2 مبني على Chromium؛ لا يُعرض لبيب كمحرك مستقل عنه. المرجع: https://learn.microsoft.com/en-us/microsoft-edge/webview2/

روابط المتجر هي الروابط التي قدّمها مالك المنتج، بالعربية والإنجليزية. لا يوجد رابط مستودع عام في إعدادات Git الحالية؛ لذلك لم يُختلق رابط GitHub. ترخيص التطبيق متاح في الموقع، ومعلومات المصادر داخل التطبيق.

حفظ بيانات المتصفح المحلي لا يعني أن المواقع والخدمات الخارجية تعمل دون اتصال أو دون سياساتها الخاصة. تم توضيح ذلك في قسم الخصوصية. بعض الصور تستخدم بيانات عرض. رابط التنزيل مخصص لـ Windows.

بعد تعيين النطاق النهائي يمكن إضافة canonical وsitemap وروابط Open Graph مطلقة باستخدام النطاق الفعلي، دون نطاق افتراضي وهمي.
