# Labeeb 0.1.21

Updates the Arabic/English keyboard shortcuts dialog: F11 enters/exits page fullscreen; Ctrl+L / Alt+D / F6 focuses the address and reveals controls in fullscreen; Escape hides revealed fullscreen controls.

This is a text-only UI change. Shortcut behavior is unchanged from 0.1.20, whose 74-test run remains the behavioral evidence. No additional runtime or visual test is claimed. Source strings were checked in both languages. Build log: windows-0.1.21-build.log.

TypeScript, Vite production build, native Windows release compilation and NSIS bundling passed (build exit 0).
